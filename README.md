# Stack Using Linked List

## 📌 Project Overview

**Stack Using Linked List** is an interactive web-based application designed to demonstrate the working of a Stack data structure implemented using a Linked List. The application allows users to perform fundamental stack operations through a simple and user-friendly interface while visualizing the current state of the stack after each operation.

This project helps students understand the **LIFO (Last In, First Out)** principle and how linked lists can be used to implement dynamic data structures.

## ✨ Features

- **Push:** Insert a new element at the top of the stack.
- **Pop:** Remove the top element from the stack.
- **Search:** Search for a specific element in the stack.
- **Display:** Visualize the current elements of the stack.
- **Dynamic Visualization:** View the updated stack after every operation.
- **Interactive Interface:** Perform operations using buttons without reloading the webpage.
- **Input Validation:** Handle invalid inputs and operations on an empty stack.

## 🛠️ Technologies Used

- **HTML (`index.html`)** — Structures the webpage and its interface.
- **CSS (`style.css`)** — Provides styling, layout, and visual design.
- **JavaScript (`script.js`)** — Implements stack operations and dynamic visualization.

## 🧠 Data Structure Concepts

This project demonstrates the following concepts:

- Stack operations and the LIFO principle.
- Linked list nodes and pointers/references.
- Dynamic memory concepts.
- Insertion and deletion at the top of a stack.
- Searching and traversing linked list elements.
- Time complexity of basic stack operations.

## ⚙️ How to Run the Project

1. Clone or download this repository.
2. Extract the project files if downloaded as a ZIP.
3. Open the `index.html` file in any modern web browser.
4. Enter values and use the available buttons to perform stack operations.

No additional software or external libraries are required.
